1. INTRODUCTION
---------------

The buck converter (step-down converter) is a high-efficiency DC-DC
converter that produces a lower output voltage from a higher input
voltage. Typical efficiency ranges from 85% to 95%, making it ideal
for battery-powered and energy-efficient applications.

Key Advantages:
• High efficiency (85-95%)
• Compact size
• Regulated output
• Low output ripple
• Cost-effective

Typical Applications:
• USB power adapters (12V/24V → 5V)
• Automotive electronics (12V → 5V/3.3V)
• Battery-powered devices
• Industrial power supplies

2. BUCK CONVERTER TOPOLOGY
---------------------------

Basic Circuit:

        Vin (+)
         |
         |
      [Q1] ← PWM Control
         |
         +----[L]----+-----> Vout (+)
         |           |
        [Q2]       [Cout]   Load
         |           |
        GND         GND

Components:
• Q1: High-side switching MOSFET (N-channel or P-channel)
• Q2: Low-side synchronous MOSFET (N-channel) or Schottky diode
• L: Output inductor (energy storage)
• Cout: Output filter capacitor
• PWM Controller: Generates switching signals

Operating Principle:
1. When Q1 ON, Q2 OFF: Current flows through L to load and Cout
2. When Q1 OFF, Q2 ON: Inductor current freewheels through Q2
3. Inductor stores energy during ON time, releases during OFF time
4. Output capacitor filters ripple, maintains steady voltage

3. DESIGN PROCEDURE
-------------------

Step-by-Step Design Process:

STEP 1: Define Specifications
------------------------------
• Input voltage range: Vin(min), Vin(max)
• Output voltage: Vout
• Output current: Iout(max)
• Switching frequency: fsw (typical: 100kHz-500kHz)
• Output ripple voltage: ΔVout (typical: 1-2% of Vout)

STEP 2: Calculate Duty Cycle
-----------------------------
Duty cycle is the fraction of time Q1 is ON:

D = Vout / Vin

For worst case (maximum Vin):
D(min) = Vout / Vin(max)

For best case (minimum Vin):
D(max) = Vout / Vin(min)

Note: Practical duty cycle range is 10% to 90%

STEP 3: Select Inductor Value
------------------------------
The inductor value determines current ripple:

L = (Vin - Vout) × D / (ΔI × fsw)

Where:
• L = Inductance (H)
• ΔI = Inductor current ripple (A)
  Typical: ΔI = 0.2 to 0.4 × Iout (20-40% ripple)
• fsw = Switching frequency (Hz)

Inductor Current Ratings:
• DC current rating: Iout + ΔI/2 (with margin)
• Saturation current: 1.3 × Iout minimum

STEP 4: Select Output Capacitor
--------------------------------
Output capacitor determines output voltage ripple:

C = Iout × (1-D) / (fsw × ΔVout)

Alternative formula (using inductor ripple):
C = ΔI / (8 × fsw × ΔVout)

Capacitor Requirements:
• ESR: Low ESR critical for low ripple
  Typical: <50mΩ for good performance
• Voltage rating: 1.5 × Vout minimum
• Ripple current rating: >ΔI

Recommended Types:
• Ceramic (low ESR, compact)
• Polymer (good compromise)
• Tantalum (stable, moderate ESR)
• Electrolytic (high capacitance, higher ESR)

STEP 5: Select MOSFETs
----------------------
High-Side MOSFET (Q1):
• Voltage rating: 1.5 × Vin(max)
• Current rating: >Iout (with 1.5x margin)
• Rds(on): Low for efficiency
  Target: Pconduction < 0.5-1W
  Rds(on) < Ptarget / (D × Iout²)

Low-Side MOSFET (Q2):
• Voltage rating: Same as Q1
• Current rating: >Iout
• Rds(on): Very low (conducts longer than Q1)
  Rds(on) < Ptarget / ((1-D) × Iout²)

Alternative: Use Schottky diode instead of Q2 (cheaper, simpler drive)

STEP 6: Calculate Efficiency
-----------------------------
Major losses:
1. MOSFET conduction: P = I² × Rds(on) × duty_cycle
2. MOSFET switching: P = ½ × V × I × (tr + tf) × fsw
3. Inductor DCR: P = I² × DCR
4. Diode forward drop (if used): P = Vf × I × (1-D)

Estimated efficiency:
η = Pout / (Pout + Plosses)

Typical efficiency: 85-95%

4. COMPONENT SELECTION GUIDELINES
----------------------------------

INDUCTOR SELECTION:
-------------------
Critical Parameters:
1. Inductance value (µH)
2. DC current rating (A)
3. Saturation current (A)
4. DC resistance / DCR (mΩ)
5. Size and mounting

Recommendations:
• Use shielded inductors to minimize EMI
• Low DCR for high efficiency
• Saturation current >1.3 × Iout(max)
• Common types:
  - Power inductors (surface mount)
  - Toroidal inductors (high current)
  - Drum core (good shielding)

CAPACITOR SELECTION:
--------------------
Output Capacitor:
• Ceramic: Best performance (low ESR, low ESL)
  - X5R or X7R dielectric
  - Multiple in parallel for high capacitance
  - Voltage rating >2× Vout for ceramics (derating)

• Polymer: Good compromise
  - Low ESR (20-50mΩ)
  - Stable over temperature
  - Higher voltage available

• Electrolytic: High capacitance
  - Use low-ESR types
  - Shorter lifetime (watch ripple current)
  - Need ceramic bypass

Input Capacitor:
• High ripple current capability
• Low ESR to minimize input voltage ripple
• Place close to MOSFETs
• Typical: 10-100µF ceramic + bulk electrolytic

MOSFET SELECTION:
-----------------
Key Parameters:
1. Vds rating: >1.5 × Vin(max)
2. Id rating: >1.5 × Iout(max)
3. Rds(on): As low as practical
4. Qg (gate charge): Lower = faster, more efficient
5. Package: Good thermal performance

Recommended MOSFETs by Current:
• 1-5A: IRFZ44N, IRF540N, FQP30N06L
• 5-20A: IRF3205, IRFB4110, IPB80N06S2L
• 20-50A: IRFB4115, IPB107N20N3, BSC050N10NS3

5. PCB LAYOUT GUIDELINES
-------------------------

Critical Design Rules:

1. HIGH CURRENT PATH:
   • Minimize loop area: Vin → Q1 → L → Cout → GND → Vin
   • Wide traces for high current (1mm² per Amp guideline)
   • Short, direct connections

2. SWITCHING NODE:
   • Keep Q1 drain, Q2 drain, and L connection small
   • Minimize parasitic capacitance and inductance
   • Route away from sensitive signals

3. GATE DRIVE:
   • Keep gate traces short
   • Use ground plane for return
   • Gate resistor close to gate pin

4. INPUT/OUTPUT:
   • Ceramic capacitors close to MOSFETs
   • Bulk capacitors can be slightly farther
   • Star ground for input/output

5. GROUNDING:
   • Solid ground plane under circuit
   • Separate power and signal grounds if possible
   • Connect at single point (star ground)

6. THERMAL:
   • Thermal vias under MOSFETs and inductors
   • Copper pour for heat spreading
   • Consider heatsinks for >5W dissipation

Recommended Layer Stackup (4-layer):
• Layer 1: Component side (signals, some power)
• Layer 2: Ground plane
• Layer 3: Power plane (Vin, Vout)
• Layer 4: Bottom (additional routing)

6. TROUBLESHOOTING
------------------

Common Issues and Solutions:

PROBLEM: No Output Voltage
CAUSES:
• No PWM signal to gate
• MOSFET not turning on (check Vgs)
• Open circuit (broken trace, bad solder)
• Inductor saturated or shorted
SOLUTIONS:
• Verify PWM controller operation
• Check gate voltage with oscilloscope
• Inspect PCB for defects
• Test inductor with multimeter (should be low resistance)

PROBLEM: Output Voltage Too Low
CAUSES:
• Duty cycle too low
• Excessive losses (Rds(on), DCR)
• Load current exceeds design
• Inductor saturating
SOLUTIONS:
• Increase duty cycle (adjust feedback)
• Use lower Rds(on) MOSFETs
• Check load current
• Use higher saturation current inductor

PROBLEM: Output Voltage Too High
CAUSES:
• Duty cycle too high
• Feedback error
• Light load or no-load instability
SOLUTIONS:
• Verify feedback network
• Add minimum load resistor
• Check compensation network

PROBLEM: High Output Ripple
CAUSES:
• Insufficient output capacitance
• High ESR capacitor
• PCB layout issues
• Wrong inductor value
SOLUTIONS:
• Add more output capacitance
• Use low-ESR capacitors
• Improve PCB layout
• Recalculate inductor value

PROBLEM: Overheating
CAUSES:
• Switching losses too high
• Conduction losses too high
• Poor thermal design
• Operating above rated current
SOLUTIONS:
• Reduce switching frequency
• Use lower Rds(on) MOSFETs
• Add heatsink
• Verify load current within spec

PROBLEM: EMI/Noise Issues
CAUSES:
• Poor PCB layout
• Fast switching edges
• No input filtering
• Inadequate grounding
SOLUTIONS:
• Minimize switching node area
• Add gate resistor to slow edges
• Add input filter (ferrite + capacitor)
• Improve grounding

7. DESIGN EXAMPLE
-----------------

Specification:
• Input: 12V DC (±10%)
• Output: 5V DC
• Output Current: 3A max
• Switching Frequency: 100kHz
• Output Ripple: <50mV

STEP 1: Duty Cycle
D = Vout / Vin = 5V / 12V = 0.417 (41.7%)
D(min) = 5V / 13.2V = 0.379 (37.9%)
D(max) = 5V / 10.8V = 0.463 (46.3%)

STEP 2: Inductor Value
Target ripple: ΔI = 0.3 × 3A = 0.9A (30%)

L = (12V - 5V) × 0.417 / (0.9A × 100kHz)
L = 32.5µH

Choose standard value: 33µH or 47µH

Inductor specs:
• Inductance: 47µH
• DC current: >3.5A
• Saturation current: >4A
• DCR: <50mΩ
Example: Würth 744 043 047 (47µH, 4.2A, 43mΩ)

STEP 3: Output Capacitor
C = 0.9A / (8 × 100kHz × 0.05V)
C = 22.5µF

Choose: 2× 22µF ceramic (X5R/X7R, 10V) in parallel
Or: 1× 47µF polymer capacitor

ESR requirement:
ΔVESR = ΔI × ESR
ESR < 50mV / 0.9A = 55mΩ

STEP 4: MOSFET Selection
Voltage rating: 1.5 × 13.2V = 20V → Use 30V-60V MOSFETs

High-side Q1 (ON time: 41.7%):
Target loss: 0.5W
Rds(on) = 0.5W / (0.417 × 3² × 1.5) = 88mΩ
Choose: IRF540N (100V, 33A, 44mΩ) - overspec'd but common

Low-side Q2 (ON time: 58.3%):
Rds(on) = 0.5W / (0.583 × 3² × 1.5) = 63mΩ
Choose: IRFZ44N (55V, 49A, 17.5mΩ) - excellent for low-side

Alternative: Use MBR20100CT Schottky diode (simpler)

STEP 5: Input/Output Capacitors
Input: 2× 22µF ceramic (close to MOSFETs)
      + 100µF electrolytic (bulk)

Output: 2× 22µF ceramic + 47µF electrolytic

STEP 6: Estimated Efficiency
Q1 conduction: 0.044Ω × 3² × 0.417 = 0.165W
Q2 conduction: 0.0175Ω × 3² × 0.583 = 0.092W
Inductor: 0.043Ω × 3² = 0.387W
Switching: ~0.2W (estimated)
Total losses: ~0.84W

Pout = 5V × 3A = 15W
Efficiency = 15W / (15W + 0.84W) = 94.7%

Excellent efficiency for this design!
